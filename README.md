# LinkedIn Content Roadmap

Roadmap e backlog editorial para organizar conteúdos técnicos publicados e planejados para o LinkedIn.

## Objetivo

Centralizar ideias, estudos, roteiros e registros de publicação em Markdown. O repositório permite visualizar o que já foi publicado, o que está em produção e quais temas devem entrar na sequência, sem depender de uma aplicação ou ferramenta externa.

## Séries

* **[IAM Platform](iam-platform/README.md):** construção prática de uma plataforma de identidade e acesso com Java, Spring Boot, DDD e Clean Architecture.
* **[Spring](spring/README.md):** funcionamento interno e recursos essenciais do ecossistema Spring.
* **[Testing](testing/README.md):** estratégia e práticas de testes automatizados.
* **[Security](security/README.md):** fundamentos e controles para aplicações e APIs seguras.
* **[Microservices](microservices/README.md):** decisões e padrões de arquiteturas distribuídas.

## Status

* `backlog`: ideia registrada e ainda não iniciada.
* `in-progress`: conteúdo em estudo, redação, criação visual ou revisão.
* `published`: conteúdo publicado; data e link devem ser preenchidos quando conhecidos.

O checklist dentro de cada post registra o progresso editorial com mais precisão.

## Convenção de nomes

Use `NN-titulo-em-kebab-case.md`, com número de dois dígitos, letras minúsculas, sem acentos, espaços ou caracteres especiais. Exemplo: `09-testcontainers-com-postgresql.md`.

## Fluxo de produção

`backlog` → `in-progress` → `published`

A movimentação do arquivo deve acompanhar o estado real do conteúdo. Ao mudar o status, atualize o checklist, o README da série e esta visão geral.

## Como adicionar um novo post

1. Escolha a série e confirme o próximo número.
2. Copie o [template de post](templates/post-template.md) para a pasta `backlog` correspondente.
3. Renomeie o arquivo conforme a convenção e preencha os campos conhecidos.
4. Marque apenas as etapas efetivamente concluídas.
5. Atualize a tabela da série e a tabela geral.
