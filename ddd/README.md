# Série — Domain-Driven Design

Esta série reúne conteúdos didáticos sobre Domain-Driven Design, incluindo seus aspectos estratégicos e táticos.

O objetivo é estudar como modelar sistemas a partir das regras, conceitos e linguagem do negócio, mantendo o domínio protegido de detalhes de infraestrutura.

## Assuntos abordados

* Linguagem Ubíqua
* Domínio e subdomínios
* Entidades
* Value Objects
* Agregados
* Domain Services
* Domain Events
* Repositories
* Bounded Contexts
* Context Mapping
* DDD estratégico e tático

## Organização

* `backlog`: ideias e conteúdos ainda não iniciados.
* `in-progress`: conteúdos em estudo, produção ou revisão.
* `published`: conteúdos já publicados no LinkedIn.

## Objetivo profissional

Aprofundar os estudos em DDD e demonstrar sua aplicação em projetos Java, Spring Boot e na construção da IAM Platform.
