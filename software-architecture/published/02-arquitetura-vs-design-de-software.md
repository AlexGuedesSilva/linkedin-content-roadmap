## Objetivo do post

Explicar a diferença entre Arquitetura de Software e Design de Software, demonstrando que ambos possuem responsabilidades distintas, mas complementares. O objetivo é ajudar desenvolvedores a compreender quando pensar na estrutura geral da aplicação e quando focar nos detalhes da implementação, mostrando como esses conceitos trabalham juntos para construir sistemas escaláveis, organizados e de fácil manutenção.

## Mensagem principal

Arquitetura define a estrutura e as decisões de alto nível do sistema.

Design define como cada componente será implementado para atender essa arquitetura.

Os dois conceitos não competem entre si; eles se complementam e são essenciais para a construção de software de qualidade.
