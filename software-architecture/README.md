# Série — Arquitetura de Software

Esta série reúne conteúdos didáticos sobre princípios, estilos e decisões de arquitetura de software.

O objetivo é compreender como organizar aplicações para que sejam testáveis, desacopladas, sustentáveis e preparadas para evoluir.

## Assuntos abordados

* Separação de responsabilidades
* Baixo acoplamento e alta coesão
* SOLID
* Clean Architecture
* Arquitetura Hexagonal
* Ports and Adapters
* Monólito Modular
* Microsserviços
* Arquitetura orientada a eventos
* CQRS
* Event Sourcing
* Decisões arquiteturais e trade-offs

## Organização

* `backlog`: ideias e conteúdos ainda não iniciados.
* `in-progress`: conteúdos em estudo, produção ou revisão.
* `published`: conteúdos já publicados no LinkedIn.

## Objetivo profissional

Registrar estudos sobre arquitetura e relacioná-los com projetos reais desenvolvidos com Java, Spring Boot, DDD e segurança.
