# Série Spring

## Descrição

Explora os mecanismos internos e os principais recursos do ecossistema Spring, do contêiner de IoC à cadeia de segurança.

## Objetivo

Explicar como o Spring funciona por dentro e transformar abstrações do framework em decisões de engenharia mais conscientes.

## Tecnologias e assuntos

IoC, injeção de dependência, beans, ApplicationContext, Spring Boot, auto-configuração, AOP, transações, web e segurança.
