# Série Security

## Descrição

Apresenta fundamentos e práticas para proteger APIs, identidades, credenciais, comunicações e operações distribuídas.

## Objetivo

Organizar uma trilha progressiva de segurança aplicada, ligando conceitos criptográficos, protocolos e controles defensivos.

## Tecnologias e assuntos

Autenticação, autorização, JWT, criptografia assimétrica, OAuth 2.0, OpenID Connect, TLS, OWASP, senhas, secrets e auditoria.
