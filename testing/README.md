# Série Testing

## Descrição

Reúne práticas de testes automatizados aplicadas a domínio, casos de uso, persistência, APIs e arquitetura.

## Objetivo

Construir uma visão prática sobre estratégia de testes, isolamento, integração e confiança na evolução do software.

## Tecnologias e assuntos

JUnit, Mockito, Testcontainers, JaCoCo, MockMvc, Spring Boot Test, ArchUnit, testes de contrato e padrões de fixtures.
